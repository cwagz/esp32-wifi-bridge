ESP32 WiFi Bridge

SSL passthrough from Ethernet to a Tesla Powerwall Wi-Fi AP. Flash from this page (Web Serial).

Web Serial is not available. Use Chrome, Edge, or Opera.
Loading version…

Requirements

  • Chrome, Edge, or Opera
  • ESP32-S3-POE-ETH on USB
  • Hold BOOT while plugging in if the port does not appear

After flashing

  • Connect Ethernet (PoE or USB power)
  • Open http://powerwall.local/ or the Ethernet IP
  • Set an admin password (username is admin)
  • Save Powerwall Wi-Fi credentials
  • Optional: Ethernet tile → static LAN IP
  • Locked out: hold BOOT 15 seconds (clears password, forces DHCP)
